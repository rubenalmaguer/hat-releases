Work with an agent

An agent with a terminal, such as Claude Code, can run every step for you, from import to export. Ask in plain words; you decide what ships in the review page.

  1. Install hat. Open the downloaded hat.exe. It installs itself for you (no admin rights), puts hat on your PATH and keeps itself up to date. It asks for your model keys and offers to connect the agents it finds (Claude Code, Codex, OpenCode).

  2. Ask for the job. The agent finds what it needs in hat help and runs the steps.

    • Import job.sdlppx, translate it into Spanish (Mexico), run the common checks and open the review.
    • Proofread the subtitles in this folder and check them against our subtitle limits.
    • Turn house-style.md into checks and run them on every file.

  3. Review together. In the page, the agent works beside you: it reads the segments, suggests targets and flags problems, each batch as a set in the Suggestions tab. It never changes a target; you accept, edit or dismiss. “This” is the segment you chose.

    • Is this segment right?
    • Find every place “account” is translated differently and suggest one term.

  4. Finish. Click Done in the page, then ask for the files back.

    • Export the job and make the QA report.

What hat does

Steps are separate commands, so a job can stop, be checked and go on.

Your files, as they are

Trados SDLXLIFF and SDLPPX packages, SRT subtitles and HTML pages. Export puts the targets back without touching anything else.

AI targets

OpenAI, Gemini, Anthropic or a gateway, with your own keys, your glossaries, guidelines and memory matches.

Checks

Tags, numbers, terms, subtitle limits and spelling, plus checks written from your style guide and tested on examples.

AI proofreading

Suggestions for each segment, verified a second time, with the reason for every change.

Review in the browser

Source, target and checks side by side; subtitles with their video. Saved as you go, or packed as one page for a reviewer elsewhere.

Reports

A QA report and a Trados-like analysis, as Excel files to hand over.

hat translate job.sdlppx.es-MX.hat.json
hat qa job.sdlppx.es-MX.hat.json --checks @common
hat proof job.sdlppx.es-MX.hat.json --verify
hat review job.sdlppx.es-MX.hat.json
hat export job.sdlppx.es-MX.hat.json
hat help

Advanced setup

For what the installer skipped, or when something doesn’t work.

Add a model key later

Type it yourself: hat reads it at a prompt that doesn’t show it, so it never passes through the agent.

hat keys set openai
hat keys set gomodel --base-url https://your-gateway

Connect an agent by hand

The first adds hat to every agent it finds; the second, to Claude Code alone. Restart the agent afterwards.

hat mcp install
claude mcp add hat -- hat mcp

Codex can’t run hat

Codex runs commands as another Windows user, who can’t see hat. Once Codex is connected, hat’s own tools run hat for it. If it still needs hat in its own shell, add this to .codex\config.toml in your user folder, or use Full access.

[windows]
sandbox = "unelevated"

[sandbox_workspace_write]
writable_roots = ['C:\Users\you\AppData\Local\hat']
network_access = true

Blocked by security software

Add an exception for hat.exe in %LOCALAPPDATA%\Programs\hat.

Uninstall

Settings › Apps › hat › Uninstall, or hat uninstall. Your keys, profiles and cache stay unless you say so.
